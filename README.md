# 📷 Photography Studio & Framing Portfolio

A modern, brand-agnostic photography studio portfolio web application template built with Next.js App Router, React, TypeScript, Framer Motion, and Tailwind CSS.

---

## ✨ Main Features

- **🎨 Centralized Brand Configuration**: Easily update studio details, location, phone, social handles, and packages from `data/portfolioData.ts`.
- **📅 Dynamic Date Calculations**: Automatically computes years of experience, active booking years, reference IDs, and copyright timestamps based on system date.
- **🖼️ Interactive Custom Framing Studio**: Real-time 3D style frame previewer with material selection (Acrylic, Teak Wood, Canvas) and instant price calculation across custom frame sizes.
- **📷 Filterable Gallery & Full-Screen Lightbox**: Categorized photography portfolio with a full-screen EXIF-enabled lightbox modal.
- **📋 Dual Consultation & Framing Order Modal**: Multi-tab booking popup for scheduling event shoots or placing custom frame orders.
- **💫 Dynamic Animations & Responsive Design**: Smooth page transitions, micro-interactions, and preloader powered by Framer Motion, fully optimized for mobile and desktop screens.
- **🧪 Comprehensive Unit Test Suite**: 100% component test coverage with Vitest and React Testing Library.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16.3 (App Router, Turbopack)
- **UI Library**: React 19 & Lucide Icons
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion & AOS
- **Testing**: Vitest & React Testing Library
- **Language**: TypeScript

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run unit tests
npx vitest run

# Build for production
npm run build
```
